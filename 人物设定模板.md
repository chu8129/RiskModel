# 人物设定（role_prompt）模板与各部分作用

> 本体来源：`chat_utils.py:29 get_talk_role_prompt(talk_role, lan, ...)`
> 语音场景入口：`chat_with_voice_generator.py:52 get_first_message(talk_roles)`（把每个角色的 role_prompt 拼成 `system` 消息）
> 模板取值表：`chat_prompts.json`（`man` / `woman` / `me` / `single_chat_requirements`）

---

## 0. 一句话结论

一段"人物设定"= **把 `talk_role` 里的若干字段按固定顺序、用换行拼成一个字符串**，作为 `role=system` 的消息送给 LLM。
字段本身几乎不做加工，唯二的处理是**代词替换**和**性别码翻译**。整段拼接顺序见第 2 节，各字段作用见第 3 节。

---

## 1. 输入：`talk_role` 提供哪些字段

`get_talk_role_prompt` 只读取下列键（其余字段如 `character_image` / `level_benefit` / `prologue` 不参与人设拼接）：

| 字段                          | 类型      | 用途                                             | 源码                 |
| ----------------------------- | --------- | ------------------------------------------------ | -------------------- |
| `name`                      | str       | 角色名                                           | `chat_utils.py:36` |
| `gender`                    | str       | 性别文字（备选）                                 | `:37`              |
| `gender_id`                 | int       | 性别码，**优先级高于 `gender`**          | `:42-55`           |
| `introduce`                 | str       | 角色简介                                         | `:58`              |
| `prompt`                    | str       | 性格/人设长描述                                  | `:59`              |
| `intimacy_level`            | int       | 当前亲密度                                       | `:84-90`           |
| `max_intimacy_level`        | int       | 亲密度上限                                       | `:85`              |
| `private_memories`          | list[str] | 私有记忆                                         | `:93`              |
| `common_memories`           | list[str] | 共有记忆（兜底）                                 | `:91`              |
| `generated_common_memories` | list[str] | 生成版共有记忆（**优先**）                 | `:92`              |
| `aboutme`                   | str       | 用户（"我"）的设定                               | `:94`              |
| `role_relationships`        | list[obj] | 角色关系，每项含`role_name` / `relationship` | `:203-213`         |

## 2. 模板本体（拼接顺序）

```
{chat_requirements_prompt}\n
{name},{gender}{introduce}\n
{description}\n
{current_time_line}\n
{intimacy_prompt}\n
{role_relationships}\n
{private_memories}\n
{generated_common_memories | common_memories}\n
{aboutme}\n
```

源码逐行对照（`chat_utils.py:107-122`）：

```python
role_prompt = chat_requirements_prompt + "\n" \
              + name_prompt + "," \
              + gender_prompt \
              + introduce_prompt + "\n" \
              + description_prompt + "\n" \
              + current_time_line_prompt + "\n" \
              + intimacy_prompt + "\n" \
              + role_relationships_prompts + "\n"
if add_private_memories:
    role_prompt = role_prompt.strip() + "\n" + private_memories_prompts + "\n"
if add_common_memories:
    if generated_common_memories_prompts:                       # 优先生成版
        role_prompt = role_prompt.strip() + "\n" + generated_common_memories_prompts + "\n"
    else:
        role_prompt = role_prompt.strip() + "\n" + common_memories_prompts + "\n"
role_prompt = role_prompt.strip() + "\n" + about_me_prompt + "\n"
```

渲染后的形状示例：

```
冥白羽,男,冥白羽(受)•TK大學經濟學系三年級。提起白羽就會想到……
外向，內斂、沉穩,外冷內熱,魅惑人心的高手……
[当前时间线描述]

冥博灝: 冥博灝是冥白羽的堂哥
冥振威: 冥振威是冥白羽的親哥哥

2024-07-08 12:09,在激情四溢的夜晚……
……

你是TK大學經濟學系二年級……
```

## 3. 各部分作用

| #  | 部分                           | 来源                                                           | 作用                                                                       | 备注                                                                                                                       |
| -- | ------------------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1  | `chat_requirements_prompt`   | `single_chat_requirements[lan]`（`chat_utils.py:239-248`） | 单聊行为约束：扮演谁、字数上限、`角色名:台词(动作)` 格式、拒绝违规内容等 | 仅当`add_single_chat_requirements=True`。**语音场景传 `False`（`chat_with_voice_generator.py:56`），此段为空** |
| 2  | `name_prompt`                | `talk_role['name']`                                          | 角色名，放在行首，等价于"你是 X"                                           | `:36`                                                                                                                    |
| 3  | `gender_prompt`              | `gender_id` 优先，否则 `gender`                            | 性别标识                                                                   | `gender_id`: 1→`man`/男、2→`woman`/女、3→空；`gender` 为"其他/unknown"→空。末尾自带 `,`（`:36-55`）        |
| 4  | `introduce_prompt`           | `talk_role['introduce']`                                     | 角色简介/背景，最先讲"他是谁"                                              | **经代词替换**（`:80`）                                                                                            |
| 5  | `description_prompt`         | `talk_role['prompt']`                                        | 性格、说话风格、身份设定的核心长文本                                       | **经代词替换**（`:81`）                                                                                            |
| 6  | `current_time_line_prompt`   | `current_time_line['description']`                           | 当前场景/时间线描述，给模型即时语境                                        | 由入参`current_time_line` 传入；无则为空（`:96-99`）                                                                   |
| 7  | `intimacy_prompt`            | `intimacy_level/max_intimacy_level`                          | 本意输出亲密度                                                             | **死代码：`:90` 无条件清空**，实际恒为空；亲密度真正作用见第 6 节                                                  |
| 8  | `role_relationships_prompts` | `role_relationships`                                         | 角色间关系，格式`role_name: relationship\n`                              | 见`get_relationships_prompt`（`:203-213`），多项按行拼接                                                               |
| 9  | `private_memories_prompts`   | `private_memories`                                           | 仅该角色知道的私有记忆                                                     | 列表用`\n` join（`:93`）；`add_private_memories=True` 时加入                                                         |
| 10 | 共有记忆                       | `generated_common_memories` 优先，否则 `common_memories`   | 双方共享的记忆                                                             | `:91-92,118-121`；生成版非空时覆盖普通版。生成/判定逻辑见第 5 节                                                         |
| 11 | `about_me_prompt`            | `talk_role['aboutme']`                                       | 用户（"我"）是谁、与角色的关系                                             | 放在最末（`:122`）                                                                                                       |

## 4. 特殊处理

### 4.1 代词替换 `replace_pronoun`（`:61-77`）

只作用于 `introduce` 与 `prompt`，把原文里的第二/第三人称改写成"角色名/用户"：

| 原文                      | 替换为                                                 |
| ------------------------- | ------------------------------------------------------ |
| 你们 / 你們 / 我們 / 我们 | `{name}&{me}`                                        |
| 你 / 妳                   | `{me}`（`chat_prompts.json → me[lan]`，如"用户"） |
| 他（前面不是"其"）        | `{name}`                                             |
| 她                        | `{name}`                                             |

`me` 取值：`chat_prompts.get("me", {}).get(lan, "user")`（`:56`）。

### 4.2 性别优先级（`:42-55`）

`gender_id` 存在即忽略 `gender`：`1→man`、`2→woman`、`3→空`，其余→空；`gender_id is None` 时用 `gender` 原值，但"其他/unknown"→空。

### 4.3 多角色拼接（语音场景）

`chat_with_voice_generator.py:52-65`：

```python
for talk_role in talk_roles:
    role_prompt = chat_utils.get_talk_role_prompt(talk_role, self.lan, False,
                                                  current_time_line=self.current_time_line)
    role_prompts.append(role_prompt)
role_prompts_str = "\n\n".join(role_prompts)          # 多个角色人设用空行分隔
first_message = {"role": "system", "content": first_prompt, "index": 1, "talk_type": "home_chat"}
```

即多人通话时，**每个角色各拼一段，段间用 `\n\n` 连接**，整体作为唯一一条 `system` 消息（`index=1`）。

### 4.4 亲密度分支的开关

`add_single_chat_requirements` 默认 `False`（`:29`）；`add_private_memories` / `add_common_memories` 默认 `True`。语音场景全部走默认，故：**无单聊约束段、有全部记忆段**。

## 5. 共有记忆（common_memories / generated_common_memories）

人设模板里第 10 段是"共有记忆"，它有两个来源，且都不是在聊天时实时产生的。

### 5.1 谁算是"共同记忆"——写库时的类型判定

记忆落库（`core/meco/role_memory_vector_db.py:69-76`）时按**固定优先级**决定 `memory_type`：

```python
if memory_class in [friend_circle, friend_circle_comment, role_knowledge]:
    memory_type = common          # ① 最优先：朋友圈/评论/角色知识 一律 common
elif user_id and user_id != -1:
    memory_type = private         # ② 否则有有效 user_id → private
elif memory_class in [world, world_role]:
    memory_type = share           # ③ 世界观类 → share
else:
    memory_type = common          # ④ 兜底 → common
```

要点：

- 判定依据是 **`memory_class` + `user_id` 的组合，而非记忆内容本身**。
- `friend_circle` / `friend_circle_comment` / `role_knowledge` **强制 common**，即使带了 `user_id` 也算共同。
- 普通类记忆**只有带有效 `user_id`（非空且 `!= -1`）才是 private**，否则多为 common。
- 检索时据此分流（`chat_base_generator.py:2200-2240`）：common 只按 `role_id` 检索（跨用户共享），private 需 `role_id + user_id`。

### 5.2 `generated_common_memories` 的生成

由**独立任务** `ChatCommonMemoryGenerator`（`core/meco/chat_common_memory_generator.py`，入口 `ChatCommonMemory/script/run.py:20 runTask`）离线生成，与聊天生成分离：

1. **输入**：`param.leading_role_name` + `param.common_memories`（原始句子列表，多为第一人称"我…"）——`:42-43`。
2. **逐条改写**：对每条 memory 填 `chat_prompts.json → common_memory_prompt[lan]`（`chat_prompts.json:148`），任务是**把句子里所有"我"替换掉、以 `leading_role_name` 作主语**，只返回改写后的句子（`:61-64`）。
3. **调用模型**：默认 `deepseek`（`:130`）；`gpt`/`deepseek` 走 `zeroClient.llmCompletion`（`:67-77`），否则回退 `abab5.5s-chat` 的 `abab_task`（`:83-102`）。
4. **兜底/校验**：若结果为空或**不含角色名**，本地手工 `我/I/me → leading_role_name` 并加名前缀（`:104-110`）。
5. **产出**：每条存 `{"old": 原文, "new": 改写}`（`:112-115`）；`process()` 若整体为空则换 `doubao_pro` 重试一次（`:132-135`）。
6. **落库/消费**：服务端把 `new` 存进 `talk_role.generated_common_memories`；聊天时 `get_talk_role_prompt` 优先用它、为空才退到 `common_memories`（`chat_utils.py:92,118-121`）。

示例（`test_jsons/common_memory/测试示例.json`）：`"我是一个软件工程师"` → `"Eason是一个软件工程师。"`

> 记录形状差异：生成任务输出的是 `{old, new}` 列表，而 `talk_role.generated_common_memories` 实际存的是**字符串列表**（见 `test_jsons/suggestions/000_test.json:455`）；中间由服务端取 `new` 后落库。`chat_utils.py:92` 的 `"\n".join(...)` 也证实消费端拿到的是字符串列表。

## 6. 亲密度（intimacy_level）

> 注意：亲密度**不在本仓库计算**，它是客户端/服务端算好后随 `talk_role` 传入的输入字段；本仓库只消费不生产。

### 6.1 作用：给"角色福利（level_benefit）"做门槛控制

核心（唯一真正生效的用途）是把当前亲密度换算成"允许/禁止"的行为清单，再作为 `sample_messages` 喂给模型：

```
intimacy_level (输入)
  → user_level = int(talk_roles[0]["intimacy_level"])          # chat_with_voice_generator.py:429
  → get_benefit_and_filters(user_level, level_benefit, lan)    # chat_utils.py:784-802
       user_level <  unlock_level → "禁止{福利}" / "prohibit{benefit}"
       user_level >= unlock_level → 原样 "{福利}"
  → benefit_list
  → abab 请求的 sample_messages                                # chat_base_generator.py:1550,1792
```

- `level_benefit` 是角色定义里带 `unlock_level` 的行为项，示例（`test_jsons/reward.json:306-327`）：摸头(1)、约会(2)、拥抱(3)、允许做爱做的事(4)。
- 亲密度不够的项会被加上"禁止/prohibit"前缀，够了的保持原文；结果作为 `sample_messages` 送模型，从而**约束角色当前允许的互动程度**。
- 作用范围（各生成器逻辑一致）：`chat_generator.py:92`、`chat_private_generator.py:73`、`chat_novel_generator.py:69`、`chat_with_voice_generator.py:429`。**剧情通话时 `benefit_list=[]`，不启用**（`chat_with_voice_generator.py:425-426`）。

### 6.2 取值范围

- 上限由 `max_intimacy_level` 决定，样例数据全为 **10**；`intimacy_level` 实测 1~6 不等。
- 语义：`0` 陌生 → `max_intimacy_level` 最亲密；`level_benefit[*].unlock_level` 是分段阈值（示例 1~4）。
- 代码内**不做 clamp/校验**，直接 `int()`，非法值会抛异常。

### 6.3 别混淆

| 名称                 | 范围                             | 出处 / 用途                                                                             |
| -------------------- | -------------------------------- | --------------------------------------------------------------------------------------- |
| `intimacy_level`   | 0 ~`max_intimacy_level`（=10） | `talk_role` 输入，用于解锁福利（本节）                                                |
| `intimacy` (float) | 0.0 ~ 1.0，默认 0.5              | `summary.py:18,61,116`，生成**未来时间点活动/图片描述**的参数（0 陌生、1 亲密） |

另外，挂断语里的"亲密度提升 N 点"也**不是** `intimacy_level`，而是 `sum(plot_rewards[*].reward_num)`（`chat_with_voice_generator.py:557-559`）。

## 7. 注意事项 / 已知坑

1. **`intimacy_prompt` 恒为空** —— `:90` 在赋值后立即清空，`intimacy_level` / `max_intimacy_level` 实际不进入人设。
2. **`single_chat_requirements` 的 `zh / zh-Hant / zh-Hans / en` 均为空数组**（`chat_prompts.json:2-10`），只有 `zh-gpt` / `en-gpt` 有内容；由于 `lan` 白名单不含 `*-gpt`，即使打开开关也多为空。
3. **`gender` 与 `gender_id` 可能不一致** —— 代码以 `gender_id` 为准（注释称 `gender` 未适配多语言）。
4. **同名字段两处来源易混**：`talk_role['prompt']` 是"人设描述"，与 `prompt_type` / 生成 `prompt` 无关。
5. 拼接中间多次 `strip()`（`:116,119,121,122`），会吃掉前段尾部的换行，最终各段之间为**单个 `\n`**（多角色段之间为 `\n\n`）。
